Git 工作手册（前端开发常用）

本手册旨在帮助你熟练掌握 Git 在实际前端项目开发中的常见用法，涵盖分支管理、代码提交、远程操作、冲突解决等核心技能。

一、Git 分支概念

✅ 本地分支（Local Branch）

你自己电脑里创建和操作的分支，不影响远程。

git branch             # 查看本地分支
git checkout -b dev   # 创建并切换到 dev 分支

✅ 远程分支（Remote Branch）

GitHub / GitLab 上的分支。以 origin/ 开头。

git branch -r                      # 查看远程分支
git push origin dev               # 将本地 dev 推送为远程分支
git checkout -b dev origin/dev    # 拉取远程分支并创建本地分支

✅ 本地分支和远程分支的对应关系

  • 创建远程分支后，需要将本地分支与远程分支建立关联：
git push -u origin dev
  • -u 代表将当前分支与远程分支绑定，之后只用 git push 即可。

二、分支命名规范（推荐）

类型示例用途
主分支main、master正式上线代码
开发分支develop日常开发的主分支
功能分支feature/login开发某个具体功能
修复分支bugfix/login-error修复线上或测试中发现的问题
发布分支release/v1.0.0发布版本专用

三、代码提交与推送

✅ 提交修改：

git add .
git commit -m "feat: 完成登录页面布局"

✅ 推送到远程仓库：

git push origin feature/login

四、拉取和同步远程代码

✅ 拉取远程代码并合并：

git pull origin develop

✅ 获取远程所有更新（但不自动合并）：

git fetch

五、分支合并和冲突解决

✅ 合并某分支到当前分支：

git checkout develop
git merge feature/login

✅ 解决冲突：

  1. 手动修改冲突文件（删除 <<<<<<<, =======, >>>>>>> 标记）
  2. 然后提交：
git add 冲突文件名
git commit -m "fix: 解决合并冲突"

六、版本回退操作

✅ 回退最近一次提交但保留改动：

git reset --soft HEAD^

✅ 强制回退（修改内容也回退）：

git reset --hard HEAD^

七、查看日志与差异

✅ 查看提交日志（简洁）：

git log --oneline

✅ 查看改动内容：

git diff                # 工作区未 add 的差异
git diff --cached       # 已 add 但未提交的差异
git diff dev..test      # 对比两个分支差异

八、临时保存当前进度（stash）

✅ 保存当前未提交的改动：

git stash

✅ 恢复并删除 stash 内容：

git stash pop

九、删除分支

✅ 删除本地分支：

git branch -d feature/login

✅ 删除远程分支：

git push origin --delete feature/login

十、其他常用操作

✅ 初始化项目

git init

✅ 克隆远程仓库

git clone https://github.com/user/repo.git

✅ 修改最近一次提交说明：

git commit --amend -m "新的提交信息"

✅ 简历描述建议

熟练掌握 Git 版本控制，日常使用 Git 进行分支管理（feature/bugfix/release）、代码提交、远程同步、冲突解决、版本回退，配合团队协作完成多人开发流程，具备真实项目实践经验。
