抽象类

抽象类：抽象类是不能直接实例化的类，它的作用是作为基类，供其他类继承。抽象类可以包含抽象方法和具体方法。

// 关键字 abstract 来定义抽象类
abstract class Goods{
    // 定义抽象方法
   abstract  price():number
}
class Book extends Goods{
    price():number{
        return 30; // 实现price方法，返回一个具体的值
    }
}

抽象方法：在 TypeScript 中，抽象方法是一个没有方法体的方法。它的作用是声明一个方法名和方法签名（即方法的参数和返回值类型），但是不提供方法的具体实现。#️⃣ 抽象方法必须在派生类中实现。它的作用是强制任何继承 Goods 类的子类都要提供一个具体的 price 方法实现，且该方法必须返回一个 number 类型的值。

使用接口来约束类

当接口和类组合在一起使用时，其描述的是一种契约关系。如果一个类定义了接口所声明的属性和方法，则表明此类对此接口进行了实现 🦂类无须和接口声明完全一致，类只要提供接口声明的属性和方法即可，类本身也可以有自己定义的属性和方法。

// 定义接口
interface JLog{
    log():void
    desc:string
}
// ClassA对JLog接口进行了实现
class ClassA implements JLog{
    desc:string
    name:string
    constructor(des:string){
        this.desc = des;
        this.name = "ClassA类"
    }
    log(){
        console.log(this.name + this.desc)
    }
}

var clsa:JLog = new ClassA('AAA' ) // ClassA类AAA

ts的类型区分 typeof & instanceof

// typeof 基本类型使用typeof辅助类型推断
function stringOrNumber(p:string | number){
    if(typeof p === 'string'){
       // 此时编译器会将参数p推断未string类型
       console.log(p.length)
       }else{
       // 此时编译器会将参数p推断未number类型
       console.log(p/2)
       }
}

class Color{
    color:string
}
class Shape{
    size:number
}

// instanceof   class类使用instanceof辅助类型推断
function colorOrShape(p:Color | Shape){
    if (p instanceof Color){
       // 此时编译器会将参数p推断未string类型
       console.log(p.color)
    }else{
       // 此时编译器会将参数p推断未Shape类型
       console.log(p.size)
    }
}

自定义类型推断方法

function isColor(p:Color | Shape):p is Color{
    return p["color"] != undefinde;
}
function colorOrShape(p:Color | Shape){
    if(isColor(p)){
        // 此处会被推断为Color类型
        console.log(p.color)
    }
    if(isShape(p)){
        // 此处会被推断为Shape类型
        console.log(p.size)
    }
}

字面量类型与类型别名

😂字面量类型可以分为字符串字面量类型和数值字面量类型，字面量类型的作用与枚举类似，它允许我们指定一些固定的值来定义类型，如：

// 字符串字面量类型
type Align = 'centerX' | 'centerY';
function descaAlign(align:Align){
    if(align == 'centerX'){
        console.log('水平居中')
    }
    if(align == 'centerY'){
        console.log('垂直居中')
    }
}
// 水平居中
descaAlign('centerX')


// 数值字面量类型
type Size = 44 | 68;
function createAvatar(size:Size){
    if(size == 44){
        console.log('创建44尺寸的头像')
    }
    if(size == 68){
        console.log('创建68尺寸的头像')
    }
}
// 创建44尺寸的头像
createAvatar(44)

类型别名:type语法可以将一个类型映射成另一个名字，提高代码的简洁度和可读性。类型别名不会创建新的类型，只是为已有的类型定义了一个新的名字

// 使用type来定义别名，其表示后面的联合类型
type BaseAny = number | string | boolean | null
var base:BaseAny = 1
var base2:BaseAny = "hello"
var base3:BaseAny = "123"

泛型

泛型：函数名后面的尖括号中用来定义类型变量，此变量的名称是任意的。


function trace<T>(data: T): T{
    console.log('进行记录'+data);
    return data
}
var a = 3
var b = 4
var c = trace(a)+trace(b)
console.log(c);
var d = 'hello'
console.log(trace(d));

//进行记录3
//进行记录4
//7
//进行记录hello
//hello

😂 当然，在调用函数时，也可以手动设置此泛型的具体类型

// 数值
var a = 3;
var b =4;
var c = trace<number>(a) + trace<number>(b);

var d = 'hello'
var e = trace<string>(d).length

在类和接口中使用泛型

类中使用泛型的语法规则是在类名的后面加尖括号，尖括号内是泛型变量，之后在类内部的任何地方都可以直接使用此泛型变量。

class List<T>{
    l:Array<T>
    constructor(){
        this.l = []
    }
    add(obj){
        this.l.push(obj);
    }
    remove():T | undefined{
        return this.pop();
    }
}
// 创建容器
var list = new List<number>()
list.add(1);
list.add(2);
// 移除容器中的一条数据
console.log(list.remove())

😂 在进行类实例的构造时，需要提供泛型的具体类型

迭代器与装饰器

装饰器：

  • 类装饰器
  • 方法装饰器
  • 访问装饰器
  • 属性装饰器
  • 参数装饰器

装饰器：装饰器本身是一个函数，我们可以通过特殊的语法声明将其附加到类上。

// 装饰器
function classConstructorLog(constructor: Function) {
    console.log("装饰器被调用",constructor);+ 
}
// 使用装饰器对类进行修饰
@classConstructorLog
class MyObject {
    constructor() {
        console.log("My Object的构造函数");
    }
}
// 将先调用装饰器函数，在调用类的构造函数
var obj = new MyObject()

类装饰器：对于类装饰器，装饰器函数的参数即为要调用的构造函数 类装饰器也提供返回值，提供的返回值需要继承自原构造函数，可以用来为原构造函数增加新的功能

// 参数类型定义为构造函数，返回值定义为any
function classConstructorLog(constructor: new (...args: any[]) => any): any{
    console.log("装饰器被调用", constructor);
    // 返回新的构造函数
    return class extends constructor{
        other = 'other'
    }   
}
@classConstructorLog
class MyObject{
    data: string
    constructor() {
        this.data = 'data';
        console.log("my object 的构造函数");
    }
}
// 将先调用装饰器函数，再调用类的构造函数
var obj = new MyObject();
console.log(obj);

命名空间与模块

命名空间

namespace MathTool{
    // 相加功能的函数
    export function add(a:number,b:number):number{
        return a + b
    }
    // 相减功能的函数
    export function sub(a:number,b:number):number{
        return a - b
    }
    // 圆周率
    var Pi = 3.14
    // 计算圆面积的函数
    export function circleArea(radius:number):number{
        return Pi * radius * radius
    }
}

❤️ tips：

  • MathTool就是一个命名空间，其内部可以定义接口、函数、类、变量等数据结构，默认这些数据的权限都是私有的，即命名空间内部可用，如果要暴露到外部使用，则需要export导出，对于导出的数据结构，在外部使用时使用MathTool.add(1,2)的方式使用

  • 如果在一个文件中大量使用命名空间中的某一数据结构，每次调用都需要使用命名空间的名字作为前缀会有些繁琐，

  • import CircleArea = MathTool.circleArea
console.log(CircleArea(2))
// import和模块的导入无关，其只是为指定的命名空间中的circleArea方法起了一个别名

person{

两个常用的修饰符

💥在对表单进行数据绑定时，常使用lazy,trim.

lazy类似于懒加载，在某些业务场景下，并不需要实时关注输入框文案的变化，只有当输入框失去焦点后，段落中才会同步输入框中最终的文本数据

<input v-model.lazy='textField'>
<p>
    {{textField}}
</p>

trim作用是将绑定的文本数据的首尾空格去掉，<input v-model.trim="textField">
