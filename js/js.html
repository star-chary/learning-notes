常用滚动属性

属性名描述
scrollTop元素已滚动的垂直距离（像素）
scrollLeft元素已滚动的水平距离
scrollHeight元素内容的总高度，包括因为溢出而无法看见的部分
scrollWidth元素内容的总宽度，包括因为溢出而无法看见的部分
clientHeight元素的可视高度，（不包括边框、滚动条等）
cloentWidth元素的可视宽度，（不包括边框、滚动条等）
offsetHeight元素的总高度（包括边框、滚动条等）
offsetWidth元素的总宽度（包括边框、滚动条等）

保留滚动功能但隐藏滚动条 📜

.scroll{
    overflow:auto
        
    scrollbar-width: none; /* Firefox */
  -ms-overflow-style: none; /* IE and Edge */
}

/* Webkit浏览器（Chrome、Safari、新版Edge等） */
.scroll-item::-webkit-scrollbar {
  display: none;
}

键名为分类名，值为对象数组 的结构

const data = {
    '实施':[/*50个对象*/],
    '计划':[/*100个对象*/]
}

1、转成Map

const myMap = new Map(Object.entries(data))

这样 myMap.get('实施')就能拿到‘实施’的50条数据了

2、转成数组结构

const myArr = new Map(Object.entries(data)).map(([name,value])=>{
    return {
        name,
        value
    }
})
// myArr [{name:'实施',value:[/*50条数据*/]},{name...}]

js 数组常用方法

map()

map()方法创建一个 新数组,这个数组有原数组中的每个元素都调用一次提供的函数后的返回值组成

const arr = [1,4,9,16]

const newArr = arr.map(item => {
    return item * 2
})

console.log(newArr) // [2,8,18,32]

引用数据类型 ♦️

Set()

Set是一种集合，没有重复值的集合——可迭代

特点：

  • 每个值唯一（自动去重）
  • 可以存储任意类型的值（函数、对象、基本类型等）
  • 不会进行类型转换（1 和 '1' 是不同值）

创建方式

const o = new Set([1,2,3])

常用方法：

方法说明
add(value)添加一个值
delete(value)删除一个值
has(value)判断是否包含某个值
clear()清空所有值
size集合中的个数（不是length）

遍历方法

const s = new Set(['a','b'])
s.forEach((val)=> console.log(val))

for(const val of s) console.log(val)

使用场景举例

  • 去重

    const arr = [1,2,3,4,2,1]

const unique = [...new Set(arr)] // [1,2,3,4]

  • 判断元素是否存在

    • const visited = new Set()
visited.add('home')
if(!(visited.has('about'))){
    visited.add('about')
}

Map()

Map是一种键值对的集合，类似Object，但

  • 键可以是任意类型（对象、函数都行）
  • 键值对有序
  • 不共享原型链属性（不像对象可能会继承toString)

创建方式

const m = new Map()
m.set(data,123)
m.set({id:1},'user')

常用方法

方法说明
set(key.value)设置键值对
get(key)获取值
has(key)是否存在键
delete(key)删除某个键值对
clear()清空
sizeMap元素的个数

遍历方法

const m = new Map([
    ['a',1],
    ['b',2]
])

for(const [key,val] of m){
    console.log(key,val)
}

m.forEach((key,val)=> console.log(key,val))

使用场景举例

  • 统计词频

    • const wordCount = new Map()
const words = ['apple', 'banana', 'apple']

for(const word of words){
    wordCount.set(word,(get(word) || 0) +1)
}
console.log(wordCount) // Map(2) {"apple" => 2, "banana" => 1}

  • 用对象作为 key（Object 不支持）：

    const objKey = { id: 1 }
const map = new Map()
map.set(objKey, 'data')
console.log(map.get(objKey)) // data
